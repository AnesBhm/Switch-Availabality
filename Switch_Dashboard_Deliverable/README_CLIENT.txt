============================================================
SWITCH AVAILABILITY DASHBOARD - QUICK START GUIDE
============================================================

Hello! This folder contains the complete Switch Availability Dashboard application.

How to start the dashboard:
---------------------------
0. First, install the requirements located in requirements.txt file. ( pip install -r requirements.txt )
1. Inside this folder, look for a file named "run_dashboard.bat".
2. Double-click "run_dashboard.bat".
3. A black command window will open. It will automatically check for and install any necessary Python dependencies. 
4. Once it finishes loading, it will say: "Dash is running on http://127.0.0.1:8050/"
5. Open your preferred web browser (Chrome, Edge, Firefox, etc.) and go to that link: http://127.0.0.1:8050

How to close the dashboard:
---------------------------
When you are finished using the dashboard, simply close the black command window (or click inside it and press Ctrl+C). This will shut down the server.
